## Estructura de Proyecto
- Toda respuesta debe incluir o referenciar la inclusión de los CDN de Bootstrap 5 (CSS y JS Bundle), Bootstrap Icons y Google Fonts.
- Estructura semántica: <header>, <nav>, <main>, <section>, <footer>.
- Secciones obligatorias para una landing page:
  1. **Hero Section**: Navbar transparente/sticky, título impactante con gradiente, subtítulo, 2 botones CTA y elementos visuales.
  2. **Características/Servicios**: Grid de cards de Bootstrap con hover effects en CSS.
  3. **Demostración/Portafolio**: Grid interactivo o carrusel de Bootstrap (carousel-fade).
  4. **Testimonios/Métricas**: Contadores dinámicos hechos con JS.
  5. **Contacto/Footer**: Formulario estilizado con validación en Bootstrap/JS.
