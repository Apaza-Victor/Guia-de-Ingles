## Instrucciones de JS
- Escribe JavaScript moderno (ES6+) limpio y modular sin dependencias complejas.
- Agrega animaciones al hacer scroll mediante la API IntersectionObserver o la librería AOS (Animate On Scroll) vía CDN.
- Implementa micro-interacciones en botones, navegación pegajosa (sticky nav con cambio de fondo al hacer scroll) y filtrado dinámico de elementos.
- Maneja modales, tooltips y menús desplegables utilizando las API nativas de Bootstrap JS.
