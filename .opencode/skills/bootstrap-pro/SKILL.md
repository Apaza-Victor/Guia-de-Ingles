## Instrucciones de Estilo y Maquetación
- Usa Bootstrap 5 para el sistema de Grid, Flexbox y utilidades base.
- Personaliza los componentes de Bootstrap mediante variables CSS (:root) para evitar el aspecto predeterminado de Bootstrap.
- Aplica gradientes modernos, sombras personalizadas (ox-shadow) y efectos de cristal (ackdrop-filter: blur()) en style.css.
- Asegura que todos los componentes sean 100% responsivos usando clases de Bootstrap (col-12 col-md-6 col-lg-4).
- Utiliza fuentes de Google Fonts (como Poppins, Inter o Montserrat) e iconos de Bootstrap Icons o FontAwesome.
